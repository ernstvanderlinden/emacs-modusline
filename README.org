* ModusLine
  `modusline` is designed to be a lightweight and fast mode-line for viemacs's vim mode. It aims to provide a minimal and efficient mode-line setup that shows the vim mode's state.

** Features
  - Lightweight and fast operation
  - Easy customization of hidden minor modes
  - Shows the vim mode's state with customizable faces

** Comparison
  While `modusline` focuses on simplicity and speed, there are other more advanced mode-line packages available:
  - [[https://www.emacswiki.org/emacs/PowerLine][Powerline]]: A powerful, highly customizable mode-line
  - [[https://github.com/TheBB/spaceline][Spaceline]]: Derived from Powerline, with additional features
  - [[https://github.com/seagle0128/doom-modeline][Doom-modeline]]: Another derivative of Powerline, with Doom Emacs aesthetics

  If you need to hide specific minor modes from the mode-line, consider using:
  - [[https://github.com/myrjola/diminish.el][Diminish]]: A package dedicated to hiding minor modes from the mode-line

** Installation and Usage
  To use `modusline` in your Emacs setup, add the following to your Emacs configuration:

#+BEGIN_SRC emacs-lisp
  (require 'modusline)
  (modusline-mode 1)
#+END_SRC

*** Hidden Minor Modes
You can specify which minor modes to hide from the mode-line by setting `modusline-hidden-minor-modes`. For example:

#+BEGIN_SRC emacs-lisp
  (setq modusline-hidden-minor-modes
    '(modusline-mode
      aggressive-indent-mode
      auto-revert-mode
      magit-auto-revert-mode
      undo-tree-mode
      visual-line-mode
      yas-minor-mode
      smartparens-mode
      which-key-mode
      org-indent-mode
      indent-mode))
#+END_SRC

** Customization
  `modusline` offers several custom faces to personalize the mode-line's appearance according to the vim mode's state:

  - `modusline-modified-face`: For modified buffer indication
  - `modusline-unmodified-face`: For unmodified buffer indication
  - `modusline-normal-face`: For the normal state
  - `modusline-insert-face`: For the insert state
  - `modusline-visual-face`: For the visual state
  - `modusline-replace-face`: For the replace state
  - `modusline-emacs-face`: For the emacs state
  - `modusline-syntax-face`: For the syntax state
  - `modusline-syntax-visual-face`: For viemacs's syntax-visual state

  Customize these faces to match your Emacs theme or personal preference.

** Toggling modusline
  You can toggle `modusline` on or off at any time by using the command:

#+BEGIN_SRC emacs-lisp
  M-x modusline-mode
#+END_SRC
